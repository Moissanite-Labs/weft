# Variant and lineage register

Working register for [#39](https://github.com/Moissanite-Labs/weft/issues/39), baseline `main@94b9064f`, 2026-11-08. It complements the [corpus inventory](../corpus/README.md); it does not replace the eight source reports or claim a new line-by-line audit of every transcript. Its purpose is to retain the differences that matter before another implementation is selected, repaired, merged or retired.

## Reading the register

- **Active** means the checked-in implementation is exercised by current entrypoints/tests. It does not mean finished, universally correct, or the selected destination for every branch.
- **Reference** means preserved source, history or a comparison implementation. It may contain runnable fragments, defects or claims that have not been reproduced.
- **Proposed** means an experiment, design or implementation target that is not demonstrated here.
- **Conflicting** marks incompatible contracts, mechanisms or claims requiring a recorded decision. It can coexist with any status above.
- **Compatibility** means a current wrapper delegates to an implementation; its presence is not an independent implementation result.
- **Extracted** means code has been separated from its sources, but its intended runtime has not yet been validated here.

Chronological succession, extraction, reimplementation, adaptation to another stack, literal duplication and conceptual similarity are different relationships. **The newest file does not win by default. Duplicate code is not automatically redundant.** Preserve behavioral and provenance differences until a comparison establishes equivalence or a decision deliberately chooses one.

## Maintaining lineage

For the next pass, give each extracted fragment a stable record: source file and revision, transcript/turn or source block, language/toolchain, inputs/outputs, parent variants, relationship type, behavioral differences, runnable command, evidence date and unresolved decision. Match apparent duplicates by content and context before declaring equivalence. Record repaired extraction separately from the original, including the reason for each semantic change.

A retirement decision needs the preserved source, replacement coverage, migration/compatibility effect, comparison evidence and owner review. A branch can remain reference or research without becoming an immediate implementation obligation. A disagreement stays explicit until evidence or an owner decision resolves it. This register starts that work by system; fragment-level completeness is a subsequent task, not a claim made by this document.
