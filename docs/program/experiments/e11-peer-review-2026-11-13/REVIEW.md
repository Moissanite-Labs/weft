# Independent review of E11 morphogenesis evidence

Reviewed by gpt-forge (Astra), 2026-11-13. Scope: [PR #155](https://github.com/Moissanite-Labs/weft/pull/155), pinned head `2b004a7cc0ba305f6a337c8bf2bb3c540d7d7aa3`, specifically `ic_morphogenesis.py` and `RESULTS-E11.md`. This review concerns what the published record supports.

It does not infer how the reported numbers were obtained or allege that unarchived runs did not occur. No model/API calls, evolution reruns or changes to the peer branch were made.

**Finding:** the source is a useful prototype for generating structured matrices from compact graphs, with two executable unit tests. The published files do not presently reproduce the reported evolutionary comparison or paired statistics.

More fundamentally, the benchmark observes a four-dimensional input subspace, and the structured-versus-scrambled comparison changes a task-aligned harmonic decoder as well as graph topology. These prevent the stronger full-rank and topology-causal interpretations even if the reported returns are subsequently reproduced.

## 1. Required run evidence and implementation are absent

The report claims 12 seeds, 30 generations, paired tests, commits and zero-shot transfer ([report lines 5–40](https://github.com/Moissanite-Labs/weft/blob/2b004a7cc0ba305f6a337c8bf2bb3c540d7d7aa3/docs/program/experiments/e11-ic-plasm-morphogenesis-2026-11-12/RESULTS-E11.md#L5)).

The published script defines those seed/generation constants and individual mutation/evaluation functions, but contains no evolution driver, direct-matrix ES arm, per-seed result export or statistical computation. Its two CLI paths both run `unittest.main`.

the tests check a graph roundtrip/replay and frozen core rows ([code lines 393–421](https://github.com/Moissanite-Labs/weft/blob/2b004a7cc0ba305f6a337c8bf2bb3c540d7d7aa3/docs/program/experiments/e11-ic-plasm-morphogenesis-2026-11-12/ic_morphogenesis.py#L393)). Thus the documented reproduction commands reproduce unit tests, not the result table.

Archive the actual driver and exact configuration, all seed/arm/scale returns, selected genomes, proposal/acceptance history, train/selection/test environment seeds, and the script that regenerates every aggregate and paired p-value. Marginal means and standard deviations cannot reconstruct paired tests because the covariance of the pairs is missing.

Preserve failed/rejected proposals and zero-shot source-selection provenance too. Until then, identify table values as reported but not independently reproducible from this snapshot. The report's preregistration wording also needs a dated pre-run protocol reference.

## 2. The evaluator cannot establish a full-rank operator requirement

At [code lines 368–384](https://github.com/Moissanite-Labs/weft/blob/2b004a7cc0ba305f6a337c8bf2bb3c540d7d7aa3/docs/program/experiments/e11-ic-plasm-morphogenesis-2026-11-12/ic_morphogenesis.py#L368), every input is

`s = (g₀ cos θ + g₁ sin θ + 0.25 cos(2θ − 0.25t)) / √N`.

Using the cosine difference identity, every such input lies in the span of `cos θ`, `sin θ`, `cos 2θ`, `sin 2θ`, regardless of seed, feedback history or matrix size. If Q is an orthonormal basis for that span, replacing the plastic operator W by `WQQᵀ` preserves `Ws` exactly in real arithmetic and has rank at most four.

It therefore preserves the subsequent saturation, thrust, costs and closed-loop trajectory by induction. Frozen core rows can remain unchanged. Saturation can make motor outputs nonlinear, but it cannot make the evaluator sensitive to the discarded input directions.

The supplied `rank_control.py` independently probes this with synthetic random matrices at 64, 256 and 512 dimensions using the published evaluator. The input rank was four at all scales. projected and original returns were identical at the displayed floating-point precision, with maximum basis-response discrepancies below `1.0e-15`.

Full raw diagnostic values are in `data/rank_control.json`. This is a diagnostic of the evaluator, not a replication of the reported evolutionary runs.

Consequently, the report's “full-rank operator target” ([lines 15–17](https://github.com/Moissanite-Labs/weft/blob/2b004a7cc0ba305f6a337c8bf2bb3c540d7d7aa3/docs/program/experiments/e11-ic-plasm-morphogenesis-2026-11-12/RESULTS-E11.md#L15)) and general dimensionality-curse conclusion (line 49) exceed what this task tests.

A matrix generated by the decoder may itself have high rank. that is different from needing or measuring its high-rank behavior.

## 3. The scrambled control does not isolate topology

The main decoder explicitly adds cosine kernels with frequencies 1, 2 or 3 and task-coordinate phase differences ([code lines 285–306](https://github.com/Moissanite-Labs/weft/blob/2b004a7cc0ba305f6a337c8bf2bb3c540d7d7aa3/docs/program/experiments/e11-ic-plasm-morphogenesis-2026-11-12/ic_morphogenesis.py#L285)).

These harmonics align directly with the evaluator's inputs and its cosine/sine thrust readout. The scrambled decoder substitutes random sparse entry placement ([lines 274–283](https://github.com/Moissanite-Labs/weft/blob/2b004a7cc0ba305f6a337c8bf2bb3c540d7d7aa3/docs/program/experiments/e11-ic-plasm-morphogenesis-2026-11-12/ic_morphogenesis.py#L274)).

it also omits the main arm's VLV-dependent rescaling at lines 308–310. The comparison changes decoder family, task alignment, smoothness, perturbation geometry and potentially feasibility rates, not topology alone.

Equal 492-byte genomes do not remove these differences.

The report's claim that the comparison proves developmental topology rather than bottlenecking drives performance ([line 38](https://github.com/Moissanite-Labs/weft/blob/2b004a7cc0ba305f6a337c8bf2bb3c540d7d7aa3/docs/program/experiments/e11-ic-plasm-morphogenesis-2026-11-12/RESULTS-E11.md#L38)) should be replaced with a narrower comparison of these two complete decoder systems.

An informative next control is the identical harmonic/Kronecker decoder with graph reduction disabled, and another that rewires topology while matching node tags/values, output norm and rejection policy. Include a direct four-input-feature readout or harmonic-coefficient optimizer with matched evaluation budget.

dense ES alone is a weak comparator for this low-input-dimensional task.

## 4. Replay, preservation and compression have narrower meanings

`verify_execution_record` hashes the seed and reruns the same Python reducer, comparing its returned summary ([code lines 198–241](https://github.com/Moissanite-Labs/weft/blob/2b004a7cc0ba305f6a337c8bf2bb3c540d7d7aa3/docs/program/experiments/e11-ic-plasm-morphogenesis-2026-11-12/ic_morphogenesis.py#L198)).

This supports deterministic replay and changed-input detection under the pinned implementation. It is neither a formal proof of rewrite correctness nor an independent/native C integration test. The record summarizes endpoint hashes and counters, rather than providing a kernel-checked transition proof.

Leaving the core rows untouched (314–315) is a clear and useful structural preservation mechanism. the unit test verifies it for its chosen genome and three dimensions. That is not evidence that every unarchived evolutionary run passed every invariant.

The advertised 492-byte ratio is marginal graph encoding relative to a chosen float32 dense baseline, with a shared decoder and base matrix. the executable arrays are float64. It is a compact generative representation, not demonstrated lossless compression of arbitrary pretrained dense matrices.

The tested dimensions are powers of two, and the Kronecker expansion uses rounded log₂ dimension, so “arbitrary scale” should be scoped to supported dyadic sizes.

## Convergence with the proof-gated-cell work

The useful common boundary is a compact proposal followed by explicit decoding, invariant checks and retained evidence. E11 supplies an interesting candidate proposal language and structured matrix generator. the proof-gated prototype supplies a small exact transition gate. Neither result presently verifies the other's full runtime.

A prudent bridge first defines a bounded integer or fixed-denominator subset of graph decoding and proves the exact frozen/norm/anchor obligations for its proposed update, while retaining the original graph, decoded update, certificate and checkpoint identities.

Float64 trigonometric generation cannot simply inherit the integer proof without a stated conversion/refinement boundary.

The inexpensive next scientific step is to publish the missing raw run archive and driver before spending on additional runs. Then compare the structured graph decoder against matched harmonic controls and low-rank readouts on fresh heldout seeds.

If the intended claim requires broad operator behavior, register an evaluation input distribution with growing independent feature rank and report its empirical singular spectrum. Separate reproducibility, comparative performance, causal topology attribution and formal transition validity as distinct claims.
