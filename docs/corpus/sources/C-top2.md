## 3. Ideas, claims, mechanisms

### Architecture / runtime
- **Unified Memory Biomatrix Bus with fixed offsets** — dissertation-mac:25-33; whitepaper:31-39. Focal Nerve at 0x10000000, Sympathetic Current at 0x20000000, Hippocampus Archive at 0x30000000, "page-locked" and "pinned to physical frames". Category: engineering-contract / vision-language. *Mechanism actually used:* a Python `multiprocessing.shared_memory` block with the symp array placed straight after the focal array (offset = focal_bytes = 393,216), no hippocampus, no page locking, no physical pinning (dissertation-mac:235-248; mac:209-227). **Contradiction:** offsets in prose vs code. Falsified by: inspecting `shm` layout or an `mlock` call (absent).
- **Zero-copy CPU↔GPU via UMA** — mac:3; dissertation-mac:21-23; ahraz:267. Category: hardware. *Actual:* every read/write does `.cpu().numpy()` / `torch.from_numpy(...copy()).to("mps")` (mac:230,234; soc:104,107; ahraz:112,115), which are explicit copies. Falsified by: profiling shows host↔MPS copies per step.
- **Direct kernel ingestion "in a single clock cycle"** — dissertation-mac:39 (SMC keys TC0P/TG0P, mach_vm); whitepaper:44 "<0.5 ms… bypassing subprocess forks". Category: hardware/engineering-contract. *Actual:* mac:324 forks `sysctl` (a subprocess, which is exactly what the prose says is bypassed); ahraz:66 uses `sysctlbyname` (no SMC); test:102 tolerates 5 ms while its docstring (88) says <1 ms. No code reads TC0P/TG0P. Falsified by: timing; grep for an SMC key read (none).
- **Thermal-level→°C synthesis** — mac:327-335; ahraz:69-71. A discrete throttle level (0/1/2) is mapped to invented temperatures plus `random()`. The displayed "SMC Performance Core Thermal Vector" (mac:379; xtra:17) is therefore partly random. Category: mechanism (honest label: simulated). The `machdep.xcpm` key belongs to Intel XCPM; on Apple Silicon expect a failure and the random 45-47 °C fallback.
- **Interaction-combinator language, five agents** — dissertation-mac:64-70; whitepaper:72-78. CON=telemetry ingestion, ERA=decay, DUP=cloning, VLV=taxation, SUP=superposition. **Contradiction:** dissertation code defines six (adds FRC "Fractal", dissertation-mac:211; ahraz:135); tune:137 builds the "Fractal Genotype" on FRC. Category: theory/vision-language. Note: in Lafont's interaction combinators the agents are CON/DUP/ERA, and the semantic roles given here ("ingests telemetry", "taxation") are not combinator semantics.
- **Rewrite rules** — dissertation-mac:76-78; whitepaper:84-86. ⟨CON|ERA⟩ ⟹ ∅ ("mutual annihilation") and ⟨CON|DUP⟩ ⟹ cloning ("commutation"). Category: theory. **Diverges from standard IC and from `runtime/core/weft_ic_vm.py`**: there, CON-CON / DUP-DUP annihilate, CON-DUP commute, and ERA *propagates* erasure to the aux ports rather than vanishing with its partner. The dissertation code's CON-SUP rule (281-298) spawns pairs named by `int(time.time())`, so two spawns in the same second collide in the `nodes` dict (silent overwrite).
