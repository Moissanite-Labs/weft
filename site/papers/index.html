ML Weft

Adaptive models within bounds you can check

Version 1.0 · 8 November 2026 · Overview. Each claim is labelled as running, simulated, or design.

ML Weft is an open research program from Moissanite Labs. It studies models that keep adapting after deployment, under limits that a program can verify.

Models as Cells

Self-modification bounded by distance from a saved baseline

Version 1.0 · 8 November 2026 · Runs and tested. Small-scale CPU experiments. Apple MPS results not yet measured.

A model that keeps adapting after deployment needs a limit on how far it can drift, and the limit has to be something a program can check. ML Weft treats each model as a cell.
